# ADR-0013: Node.js 22 jako wymagana wersja środowiska

- **Status:** Zaakceptowany
- **Retrospektywny:** tak
- **Data decyzji:** 2026-05-11 (źródło: commit `2a28506`)
- **Data spisania:** 2026-10-30
- **Zastępuje / Zastąpiony przez:** —

## Kontekst

CLI Prisma 5 (ADR-0002) nie działał na Node 24.

## Decyzja

`package.json` wymaga `"node": ">=22 <24"`; CI używa Node 22.

## Rozważane opcje

Brak zapisu o rozważanych alternatywach.

## Konsekwencje

**Pozytywne**

- CI działa na wersji zgodnej z Prisma 5.

**Negatywne / koszty**

- Ograniczenie zostanie, dopóki projekt używa Prisma 5.

**Niewiadome**

- Rozbieżność: `.nvmrc` wskazuje `v24.8.0` (`8e6f0b9`, bez opisu przyczyny), co jest sprzeczne z `engines`. Lokalnie pnpm ostrzega o nieobsługiwanym silniku, a testy przechodzą. Nie ustalono, która wersja jest zamierzona dla dev.

## Dowody

- `2a28506` – „require Node 22 — Node 24 incompatible with Prisma v5 CLI”
- `8e6f0b9` – „update .nvmrc to v24.8.0”
- `package.json` – `engines.node`
- `.github/workflows/ci.yml` – `node-version: 22`
